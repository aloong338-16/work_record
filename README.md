# 工记 · 工作记录助手

一个**纯本地单文件**的工作记录工具：双击 `工作记录助手.html` 即可使用，无需安装、无需联网、不连接任何服务器。

## 功能

- **工作记录**：按天记录工作内容（项目、分类、状态、耗时），支持搜索、筛选、增删改查
- **周视图**：自动汇总一周记录，一键生成可复制的周报文字，支持自定义时间段浏览
- **月报**：按月汇总工作内容，生成适合粘贴到 PPT 的汇报文字，支持任意月份直选
- **多账号**：各账号注册登录，数据按账号完全隔离，可多人共用一份软件
- **主题**：亮色 / 暗色 / 跟随系统
- **AI 润色（可选）**：默认关闭，在设置页配置 OpenAI 兼容接口后开启

## 快速开始

```bash
git clone <仓库地址>
```

克隆后**直接双击打开 `工作记录助手.html`**，注册一个自己的账号即可开始记录。

> 推荐用 Chrome / Edge 打开，并按软件内提示绑定本地数据文件，防止清理浏览器数据时丢失记录。

## 数据说明（重要）

- 所有数据（账号、记录、配置）只保存在你自己的电脑上：浏览器本地存储 + 可选的本地数据文件
- **仓库里不包含任何人的数据**；`work_data/` 等数据目录已在 `.gitignore` 中排除，请勿手动提交
- 换电脑 / 换浏览器：在设置页导出备份 JSON，或复制已绑定的数据文件，在新设备上导入 / 绑定

详细用法见 [使用说明.md](使用说明.md)。
